# PF1 熵术士

熵术士的 Foundry VTT 模组，包含中文原力资料库、每日流转专注、体质准备法术书与三项专长。

目标环境为 Foundry VTT 13 build 351、Pathfinder 1 系统 11.11。

## 安装 0.5.0

在 Foundry 设置首页打开「附加模组 → 安装模组」，将以下地址粘贴到「清单 URL」栏并安装。

```text
https://raw.githubusercontent.com/trochidae9577/pf1-entropist/main/install/module.json
```

也可[下载安装包](dist/pf1-entropist-0.5.0.zip)，将其中的文件解压到 Foundry 用户数据目录的 `Data/modules/pf1-entropist/`。在 PF1 世界的「管理模组」中启用。

0.5.0 支持复合念袭分项伤害、按等级登记新原力、13 级瞬发超念及储念器，并修正注能关联、准备位同步和整夜休息结算。升级后可在每日准备面板补登记旧角色的升级原力。
