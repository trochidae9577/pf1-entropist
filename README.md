# PF1 熵术士

熵术士的 Foundry VTT 模组，包含中文原力资料库、每日流转专注、体质准备法术书与三项专长。

目标环境为 Foundry VTT 13 build 351、Pathfinder 1 系统 11.11。

## 安装 0.4.2

在 Foundry 设置首页打开「附加模组 → 安装模组」，将以下地址粘贴到「清单 URL」栏并安装。

```text
https://cdn.jsdelivr.net/gh/trochidae9577/pf1-entropist@main/install/module.json
```

也可[下载安装包](dist/pf1-entropist-0.4.2.zip)，将其中的文件解压到 Foundry 用户数据目录的 `Data/modules/pf1-entropist/`。在 PF1 世界的「管理模组」中启用。

0.4.2 修复了 PF1 11.11 的空白法术书接入报错。有角色编辑权限的玩家可以配置四种自定义元素及 D4 对应，也可以直接修改现有组列。组列改变后请重新确定流转专注。
