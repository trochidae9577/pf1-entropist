# PF1 熵术士

熵术士的 Foundry VTT 模组，包含中文原力资料库、每日流转专注、体质准备法术书与三项专长。

目标环境为 Foundry VTT 13 build 351、Pathfinder 1 系统 11.11。目前已通过自动测试和浏览器模拟，实际 Foundry 世界的验证仍待完成。

## 安装 0.4.1

在 Foundry 设置首页打开「附加模组 → 安装模组」，将以下地址粘贴到「清单 URL」栏并点击安装。

```text
https://raw.githubusercontent.com/trochidae9577/pf1-entropist/main/pf1-entropist/module.json
```

也可以[下载安装包](dist/pf1-entropist-0.4.1.zip)，在 Foundry 用户数据目录的 `Data/modules/` 下新建 `pf1-entropist` 文件夹，把 ZIP 内的文件解压到这个文件夹。重启 Foundry 后，在 PF1 世界的「管理模组」中启用。
